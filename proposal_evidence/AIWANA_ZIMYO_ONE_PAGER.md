# Aiwana × Zimyo
## Private enterprise document intelligence with Captive Data

Zimyo brings HR, payroll, attendance, employee self-service, learning, helpdesk and related workflows together. Its public product material describes a broad HRMS surface spanning employee records, policies, documents, attendance, payroll, learning and support workflows. [Zimyo HR software](https://www.zimyo.com/hr-software/)

Aiwana adds a governed intelligence layer for the documents behind those workflows: policies, payroll guides, attendance rules, onboarding packs, help articles, compliance material, SOPs and internal knowledge.

### The difference

**Your documents. Your vectors. Your retention. Your control.**

Aiwana is designed so an enterprise can see the lifecycle of its knowledge assets: upload, parsing, OCR, extracted content, chunks, embeddings, vector indexes, graph facts, retrieval context, retention and deletion workflows. The Data Vault surfaces make that lifecycle inspectable rather than treating the model prompt as a black box.

### What is already evidenced

- Working Next.js application with dashboard, chat, sources, evidence, Data Vault, admin and settings screens.
- Auth, RBAC and tenant-scoping tests.
- PDF, DOCX, PPTX, XLSX and CSV ingestion foundation.
- Dense/sparse/hybrid retrieval, reranking, citations, grounding and abstention paths.
- Data footprint, lineage, retention and purge-request controls with automated test coverage.
- A synthetic 200-page parser benchmark: 200 pages, 270 chunks, local parse/chunk path.
- Full backend test suite: 167 passing tests; frontend production build passes.

### What the pilot should prove

1. Connect a representative Zimyo knowledge set with approved data boundaries.
2. Measure answer quality and citation correctness on real HR/payroll/helpdesk questions.
3. Run scanned documents and 100–200 page documents through the live queue and record latency.
4. Validate shared logical isolation or a dedicated customer data plane.
5. Demonstrate retention, deletion approval, purge verification and restore procedures.

### Commercially safe position

Aiwana is ready for a structured enterprise pilot and has a clear path to production hardening. This proposal does not claim a native Zimyo connector, universal 200-page OCR guarantees, zero leakage, compliance certification or a live per-customer cloud deployment. Those are validation and deployment workstreams.
